N64-era design directions

The N64 predates the web as a design medium, so the reference set is physical print — cartridge labels, boxed packaging, instruction manuals, dev-kit docs — not 90s web design. Each pair below is current vs era so you can judge the swap directly.

The palette is already there: --purple ≈ Grape, --lime ≈ Jungle Green, --coral ≈ Watermelon Red, --cyan ≈ Ice Blue — the actual N64 controller colourways.
