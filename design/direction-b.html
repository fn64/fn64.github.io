The stack

From local ROM to native app

Five stages. Each writes a file you can look at, so you can re-run any one without rebuilding the others.

01

Discover

Analyze a local ROM, retain proven facts, keep a named blocker on every unresolved bank.

→ content-free metadata
02

Recompile

Turn MIPS functions into typed Rust runners, one per MIPS function.

→ host-native code
03

Execute

Link recompiled code to a clean-room Rust implementation of the runtime surface.

→ running game logic
04

Present

Graphics, audio, input and platform integration through explicit backend seams.

→ native application
05

Prove

Grade ABI shape, code generation and deterministic behavior with executable checks.

→ reviewable evidence
