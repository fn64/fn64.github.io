Current copy, for reference:

“fn64 is a Rust runtime for Nintendo 64 static recompilation. Your recompiled ROM calls into it for the scheduler, message queues, timers, DMA and overlay lifecycle, save, input and audio.”

Three problems. The second sentence is a seven-item list that trails off rather than ends. “Calls into it for” is a clumsy verb. And that same noun-pile already appears twice more on the page — in “Not an emulator” and in the fn64-runtime crate row — so its third appearance adds nothing.

Run your recompiled ROM as a native app.

fn64 is the Rust runtime underneath: the part your recompiled game calls when it wants a thread scheduled, a file loaded, or a frame drawn.

  • Pre-alpha
  • MIT OR Apache-2.0

Why: replaces seven nouns with three verbs a reader can picture. The full surface is still listed twice below, where a reader who wants it will find it. Shortest of the options and the only one that ends on a concrete image.

B · keep the list, fix the verb

Run your recompiled ROM as a native app.

fn64 is the Rust runtime your recompiled game runs on top of. It owns the scheduler, message queues, timers, DMA, save, input and audio.

  • Boots Ocarina of Time today
  • Pre-alpha
  • MIT OR Apache-2.0

Why: “owns” is stronger than “calls into it for”, and the list drops “overlay lifecycle” to seven→six items so it ends rather than trails. Keeps the specificity if you want it up top.

C · lead with the problem

Run your recompiled ROM as a native app.

Static recompilation turns a game’s MIPS code into native code. It does not give you the machine that code expects to be running on. fn64 is that machine, in Rust.

  • Boots Ocarina of Time today
  • Pre-alpha
  • MIT OR Apache-2.0

Why: answers “why does this need to exist” before “what is it”, which is the question a newcomer actually has. Risk: three sentences is long for a lede, and it front-loads a definition.

D · one sentence, no list

Run your recompiled ROM as a native app.

fn64 is the Rust runtime a statically recompiled N64 game links against instead of an emulator.

  • Boots Ocarina of Time today
  • Pre-alpha
  • MIT OR Apache-2.0

Why: tightest, and “instead of an emulator” pre-empts the most common misreading in four words. Risk: defines partly by negation, and “links against” assumes the reader knows what that means.
