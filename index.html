fn64-discover

Start with the ROM.
Not a finished decomp.

fn64’s novel, evidence-carrying discovery pipeline recovers functions and section metadata directly from a locally supplied ROM. It can open a path for projects without a completed source decompilation; it does not pretend every ROM is solved today.
