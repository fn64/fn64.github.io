Run it

fn64 is the layer under the game: scheduler, message queues, timers, DMA and overlay lifecycle, save, input, audio. It boots Ocarina of Time today.

On this page

Without a ROM With your ROM What works Discovery grades

Without a ROM

The shell builds with no game content linked. It refuses to open an empty window and tells you what it needs instead.

cargo run -p fn64-shell -- --demo

Drives the real window, framebuffer conversion, and overlay from a synthetic RDRAM field, so the UI stack stays verifiable in a checkout with nothing to boot.

With your own ROM

Same intake contract as examples/oot-boot:

RECOMPILED_DIR=.../OOTU/RecompiledFuncs \
ROM=.../oot-ntsc-1.0.z64 \
cargo run -p fn64-shell
Your content stays local This repository contains tooling and runtime code. No game assets, no ROM bytes, no recompiled game output. Everything derived from your ROM stays on your disk and out of git.

What works today

Ocarina of Time boots in a windowed app with the RT64 renderer and working input.

Known gaps Audio is still broken (R5) and the outdoor gameplay eye-gate is unmet (R3b). Both are tracked in docs/ROADMAP.md.

Discovery grades

Boot-bank function recovery, graded against public decomp answer keys. As of August 2026.

TitleMatchedRecallWrong
Super Mario 642816 / 303092.9%0
Ocarina of Time119 / 13786.9%0
No Mercy835 / 98584.8%0
Majora’s Mask402 / 48682.7%0
WM2000698 / 84782.4%0
Kirby 64402 / 53175.7%0

Recall is what discovery found. Wrong is what it got wrong, and it is zero on every title. Missing a function costs you work; claiming a boundary that isn’t there costs you a debugging session chasing a ghost.

Graded, not blind: each run uses a donor ROM and an answer key from an existing decomp project. Cold-start discovery on an unstudied ROM is the open frontier.

Crates

One workspace, separate crates, each publishable on its own. If you only want the ABI surface, you only take fn64-abi.

CrateRole
fn64-runtimeScheduler, OS message queues, timers, PI/SI/VI/AI plumbing, rdram model, overlays
fn64-abiThe extern "C" surface recompiled code links against
fn64-shellThe executable: window, input, audio out, ROM intake
fn64-discoverROM discovery: symbol and section metadata without a decomp
fn64-cpu-runtimeLinked typed execution runtime for generated VR4300 Rust runners
